# 论文写作提纲

状态：论证框架，尚无真实实验结果。工作名 **CADloop**，暂定研究参数化 3D CAD agent harness；最终标题应依据实际方法和证据确定。

## 1. 核心论证与证据

候选研究主张：在相同基础模型、CAD 环境与预算下，利用可验证几何状态和可恢复执行的 harness，能够提高参数化 CAD 任务完成率与成本效率。当前该主张是待验证假设，不应作为论文摘要的已知结论。

| 潜在主张 | 所需实验 | 如果实验不支持 |
| --- | --- | --- |
| 几何反馈优于仅异常反馈 | 相同模型、工具和预算的反馈消融 | 限制到有证据的任务/错误类型，或撤回主张 |
| 局部恢复更省成本 | 与完整重建比较成功率、费用和调用曲线 | 分析何时恢复开销超过收益 |
| 改进来自 harness | 固定模型比较，加预算匹配与组件消融 | 排查额外上下文、候选数量与预算差异 |
| 收益可迁移 | 至少两个模型及不同任务复杂度；条件允许后增加环境 | 清楚披露覆盖范围，避免泛化结论 |
| 结果可复查 | 固定 manifest、可回放 trace、独立 evaluator | 优先补齐证据链，再做排名陈述 |

## 2. 章节骨架

1. **Introduction**：用具体建模/编辑失败说明问题；区分有效 CAD 几何、设计意图与参数化可编辑性；贡献项必须由完成的实验支持。
2. **Related Work**：分别讨论 CAD 表示/生成方法、CAD 数据与 benchmark、通用 agent harness、CAD agent 系统；避免把数据集直接写成 harness 基线。
3. **Problem Setup**：任务输入、CAD 状态、动作空间、观察、预算、终止条件、几何公差、成功定义，以及模型与 harness 的边界。
4. **Method**：实际完成的方法流程、状态反馈和恢复规则；给出可实现伪代码、工具 schema 与预算开销。不要先替未实现设计命名贡献。
5. **Experimental Setup**：官方/适配/本地协议标签、数据与去重、split、模型版本、基线来源、工具权限、预算和统计方法。
6. **Results**：按兼容协议分表报告主指标、成本曲线与置信区间；分别报告重建/编辑，不创建混合总榜。
7. **Ablations and Analysis**：反馈、检查、回滚、上下文等实际组件的消融；按复杂度与失败类型分析；包含方法失败案例。
8. **Limitations**：覆盖的表示与 CAD API、数据来源、训练污染未知项、kernel 数值误差、provider 可复现性及工业设计约束差距。
9. **Conclusion**：仅保留已有证据支持的结论。
10. **Appendix**：prompt、工具文档、环境版本、全部超参数、逐任务结果、失败定义与复现说明；不公开密钥或许可不允许发布的数据。
